# Data Automation & Report Hub Project

## Project Overview
This project demonstrates how I automated and centralized data from **nine different systems** into SQL, enabling efficient **BI reporting and dashboards** in Excel and Looker.  

The final deliverable is a **Report Hub**, a centralized portal linking all reports, dashboards, company online forms, and other commonly used resources in one convenient location.

## Workflow
1. **Data Extraction & Cleaning:** Python scripts pull and standardize data from multiple systems.  
2. **SQL Tables & Queries:** Load clean data into SQL tables, create queries for BI reports.  
3. **Dashboards & Reports:** Generate visualizations in Excel and Looker for analysis.  
4. **Report Hub:** Centralized portal linking all dashboards, reports, forms, and commonly used resources.  

---

## Technologies Used
- **Python:** Automating ETL and data cleaning processes.  
- **SQL:** Managing databases, creating tables, and running queries.  
- **Excel:** Building dashboards and ad-hoc reports.  
- **Looker:** Centralized dashboard management and Report Hub creation.  
- **Git/GitHub:** Version control, project organization, and collaboration.
